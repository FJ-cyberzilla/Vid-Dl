Sota Vid-Dl

Maintained by FJ-Cyberzilla

A lightweight, modular, and resilient downloading ecosystem optimized for Termux and Android environments, engineered for maximum performance and surgical code maintainability.

Core Architecture Philosophy

Strategy Pattern

Formalized DownloaderBackend protocol ensuring support for multiple swappable and fallible backends.

Enterprise Resilience

Exponential backoff retries via tenacity and dynamic sequential backend failovers.

Composition

Orchestration of lifecycle workflows (pause/resume/cancel) via DownloadController.

Strict Validation

Guaranteed runtime configuration integrity and payload sanitization utilizing robust pydantic models.

System Feature Matrix

Zero-Cookie OAuth

Bypasses login roadblocks natively via explicit external cookies.txt ingestion.

Smart Routing

Side-effect-free path resolution distinguishing Android shared storage from Termux directories.

Dynamic Batching

Seamless parsing of single URLs, full playlists, and local batch text files.

Safe Dry Run

Toggleable simulation mode for validating regex and path routing without altering filesystem.

Auto-Fallback

Automatic fallback to best available quality if selected target stream resolution fails.

Termux Optimized

Lightweight binary footprint designed explicitly for high stability on mobile OS platforms.

Installation Workflow

  1. pkg install ffmpeg python
  2. pip install -e .
  3. sota

Developer Shortcuts

  • Batch Shortcut: Type learn.txt when prompted to read links from your batch list in ~/Vid-Dl.
  • Extensibility: Implement protocols in core/protocols.py and bind new backends inside core/download_manager.py.
