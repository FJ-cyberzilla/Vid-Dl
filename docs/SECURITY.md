# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability in SOTA Vid-Dl, please report it immediately by opening a private GitHub Issue or by emailing the project maintainer directly at:

**Email:** cyberzilla.systems@gmail.com

Please include a detailed description of the vulnerability, steps to reproduce it, and any potential impact. We appreciate your efforts in keeping the project secure.

## Vulnerability Handling

- We aim to acknowledge receipt of your report within 48 hours.
- We will work diligently to investigate and fix reported vulnerabilities.
- Please do not publicly disclose the vulnerability until we have had sufficient time to assess and address the issue.

## Security Updates

Security patches will be released as part of our regular update cycle or as hotfixes, depending on the severity of the vulnerability.
