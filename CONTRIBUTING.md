# Contributing to Vid-Dl

Thank you for your interest in contributing to Vid-Dl! 

## Ways to Contribute

- **Reporting Bugs:** If you find a bug, please create an issue with steps to reproduce it.
- **Feature Requests:** Suggest new features by opening an issue.
- **Code Contributions:**
    - Fork the repository.
    - Create a new branch.
    - Make your changes.
    - Run tests (`pytest`) and ensure all checks pass.
    - Submit a Pull Request.

## Coding Standards

- Follow PEP 8 standards.
- Ensure all code passes `mypy --strict`.
- Adhere to the project's `GEMINI.md` conventions.
